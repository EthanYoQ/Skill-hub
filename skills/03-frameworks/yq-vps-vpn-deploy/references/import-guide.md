# 引导用户导入已交付文件

在服务端和隔离客户端验收后生成此说明。以下是供 Agent 改写的模板，不是固定文件名。替换为实际交付路径、节点名和版本。没有运行目标 GUI 时说明待用户完成导入，不伪造客户端成功状态。技术配置保持 [客户端与交付](delivery.md) 的要求。

## 先列出用户要用的文件

给出一份 YAML、TCP 主节点 PNG、UDP 备用节点 PNG、URI 备用文本和私密 MD 的可点击路径。每张码旁写清协议和角色。只有两个节点都通过验收，才将它们列为完成的双协议成品。提醒这两个节点共享 VPS 和出口 IP，不是两条独立线路。

## Clash Verge Rev

以官方 [本地配置导入](https://www.clashverge.dev/guide/profile.html) 为依据，先核对用户版本的界面标签。不要套用已停维护的 Clash for Windows 教程。常见流程如下：

1. 将本次 YAML 保存到电脑。打开 Clash Verge Rev 的“订阅”或“配置”页面。
2. 把 YAML 拖入该页面。若当前版本不支持拖入，使用“新建”，选择“本地”，再选择 YAML 并保存。按钮文字随版本核实，不让用户把文件路径粘贴到订阅 URL 输入框。
3. 在配置列表中选中刚导入的项目，确认它成为当前使用的配置。只导入文件并不等于已启用。
4. 进入“代理”页面，在本次交付的代理组中选择标为 TCP 主节点的节点。使用“规则”模式。告诉用户代理组的实际名称，不默认它一定叫 VPN。
5. 如果用户已有系统代理或 TUN，保留其状态。全新客户端先解释系统代理供遵守系统代理的应用使用；TUN 可以接管更多应用，需服务或权限支持。由用户按使用范围选择并开启。未经授权，Agent 不自动改开关、全局规则或其他订阅。
6. 用一个明确的境外 HTTPS 网站及出口 IP 检查点做验证。确认能访问后，手动选择 UDP 备用节点再测一次。延迟数值不等于真实访问成功。最后切回约定的主节点。

导入报错时，让用户提供错误文字和客户端版本，或在获准的只读环境查看日志。检查完整 YAML、内核兼容性和所选配置，不要求关闭 TLS 证书校验。不反复重装软件。若已存在全局 Merge/Script，核对最终渲染的节点、规则和 DNS，不能只检查交付源文件。

本地导入后客户端保存的是 YAML 副本。后来修改交付文件不会自动更新客户端，更新时需重新导入或按实际版本替换对应配置，并保留旧配置供回退。

## Shadowrocket

先核对用户所装版本及应用内扫码入口。官方 [App Store 页面](https://apps.apple.com/us/app/shadowrocket/id932747118) 可用于核对应用与功能，但不能代替当前界面实测。

1. 在电脑或另一台设备打开 TCP 主节点二维码 PNG。
2. 在 iPhone 或 iPad 打开 Shadowrocket，进入应用内“扫描二维码”入口，用相机扫描。不同版本可能在首页扫码图标或添加节点页面，按实际界面指出入口，不编造图标位置。
3. 允许相机权限，按提示保存节点。核对列表中出现交付说明里的 TCP 主节点名称和协议。
4. 用相同方法扫描 UDP 备用节点二维码并保存。两张码对应两个节点，需要分别导入，不能只扫描一张就认为两个都已导入。
5. 如果二维码只在当前手机上，先保存图片，再使用当前版本提供的相册识别入口。没有该入口时，在另一块屏幕展示图片，或复制本地 URI 备用文本，使用应用提供的 URI 导入入口。不要上传二维码到在线解码网站。
6. 在首页选择 TCP 主节点，打开顶部连接开关。首次出现 iOS“添加 VPN 配置”提示时，由用户允许并按系统要求认证。不索取设备解锁密码。
7. 测试境外 HTTPS 网站及出口 IP。停止或切换连接，选择 UDP 备用节点，再分别验证。两条记录同时存在不表示两条线路同时启用。

二维码只包含节点参数，不包含 Clash YAML 的 DNS、分流和 IPv6 策略。不能告诉用户扫码后已自动获得与 Windows 相同的防泄漏配置。需要规则分流时，另按当前 Shadowrocket 版本生成并核验适配配置。未完成该验证时，先引导用户在需要代理期间选择全局代理路由，而不是全局直连；说明这会让更多流量走 VPS，仍不等于已验证所有 DNS、IPv6 或绕过路径。不要依赖未知的内置国内规则就宣称符合白名单原则。

## 导入后回报与排错

请用户回报每个节点是“能访问”“只有延迟”“连接失败”还是“导入失败”，并区分 Wi-Fi 和蜂窝网络。优先索取报错文字，提醒不要公开包含凭据的二维码、URI 或配置全文。仅 TUIC 在某网络失败时，保留已验证的 TCP 主节点，检查该网络 UDP 是否受限，不为通过测试关闭证书验证。

用户发来客户端成功结果后再更新设备验收状态。没有设备反馈时，完成服务器与文件交付，并把实际设备导入、DNS、IPv6 和长期稳定性列为待验证。私密 MD 保留 SSH 密钥位置、证书续期、备份与恢复命令，供以后维护使用。
