# 实测伪装目标

## 预筛选

通过 VPS 出口 IP 查询 [RIPEstat network-info](https://stat.ripe.net/docs/data-api/api-endpoints/network-info)，记录时间、网段和 ASN。候选来自公开站点、供应商公开资料或用户指定域名，不扫描整个 ASN 的主机。

纳入当前目标、少量常见 HTTPS 站点及能找到的同 ASN 站点。供应商品牌相同不代表 ASN 相同，网站可能在 CDN。多个域名同 IP 时注明不代表多个独立地址。

从 VPS 对每个候选至少做三次 TLS 预检：

- 正常解析域名，记录实际 TLS peer IP；它可能与初次 DNS 结果不同。
- 带正确 SNI，验证证书链和域名，强制 TLS 1.3，提供 ALPN h2。
- 记录 TLS、ALPN、耗时和失败原因。对实际 peer IP 也查询 ASN。

HTTP 200、普通 TLS 或 TLS 1.2 成功不能代替以上检查。TLS 1.3 或 h2 不满足者不进入本基线比较。同 ASN 只是筛选因素，不是抗识别证明。

## 真实 REALITY 比较

预检通过后必须运行真实客户端。普通 TLS 成功但 REALITY 失败时按失败处理。

可先用隔离入口初筛，但最终结论需要在计划入口验证。临时修改运行中目标前，保存原配置和 SHA256，设置服务器自动恢复定时器，并记录短暂中断。

只改目标与配套 SNI，保持 IP、端口、UUID、密钥、路径、核心版本和测试出口一致。对合格候选做五轮交错测试并轮换顺序。每轮经显式代理检查出口 IP、稳定 HTTPS 检查点状态、固定大小下载的实际字节数。

记录逐轮结果。小样本耗时只作诊断，不足以证明长期更快。测试不能套用已有 VPN 后还声称测了直连线路。

通过 VPS 地址发送带目标 SNI 的无认证 TLS 请求，检查目标证书和合理 HTTP 行为。分别用错误 UUID 和错误 short ID 测试代理请求，均不得获得代理出口。无认证 TLS 返回网站内容不等于获得代理权限。

## 选择与恢复

私密结果表至少含域名、解析 IP、实际 peer IP、ASN、TLS/ALPN、成功轮数、错误和测试位置。

只有候选通过真实代理、证书及负向认证检查，并且有明确收益时才替换。同 ASN 候选都失败时保留合格的其他 ASN 目标。结果相当则保留现状。

试验结束先恢复原配置，核对哈希、权限、服务和代理，再取消自动恢复任务。决定换目标时，在恢复基线后单独应用已验证变更，更新服务端和受影响的 VLESS 客户端并重新验收。异常退出也要恢复；失联时依靠服务器定时器恢复。

不要把一次站点失败永久变成黑名单。未从中国运营商客户端测试时，结论只覆盖当前测试路径，不声称全国稳定或不可识别。
