## 第24章 幻灯片：每页一个结论，数据页按原文画，专家讲的内容由专家定

**适用人**：市场部、产品经理、学术推广经理；协助外部专家准备讲课幻灯片的人；需要给管理层汇报的各岗位（24-6 通用）。

**用户可能怎么开口**：
- 「下周科室会，帮我做一套产品幻灯片，突出优势，20页。」
- 「这篇论文帮我做成8页讲课用的PPT。」
- 「请的专家想讲这个题目，你给他准备点资料。」
- 「这套PPT明天送审，你帮我逐页看看。」
- 「下午要跟领导汇报这个季度的情况，帮我排个PPT。」

**本章任务链**：
- 医学/推广类：24-1 需求单 → 24-2 故事线（每页对应审核过的材料）→ 24-3 数据页（逐页写画图说明）→ 24-5 送审前逐页查（连讲者备注）→ 按流程送审。
- 专家讲课类：24-1 → 24-2 → 24-3 → 资料页按 24-5 逐页查并送审 → 送审通过以后，才用 24-4 做资料包和沟通单交给讲者 → 讲者加的页在讲课前交公司，按流程再送审。
- 管理层汇报类：24-6（独立使用，不走 24-1 到 24-5）。

**场景特有必问项**：
| 问用户什么 | 不问会出什么错 | 相关提示词或小节 |
|---|---|---|
| **最先问**：幻灯片类型和流程——科室会、给专家讲课用、区域会、内部汇报；给讲者或对外用的，要不要先送审、审完再交给谁；给选项时这几种都列上 | 医学类与汇报类走错链路；该送审的没走流程 | 24-1 首行；24-6 |
| 听众（科室、职称、医院等级；或哪一级管理者）、时长、讲者是谁 | 页数与时长不匹配；内容深浅不对 | 24-1 输入槽位；「按每页 1–2 分钟算」 |
| 有哪些审核过的材料（编号、版本、页码） | 页面内容找不到出处，被退回 | 24-1【可以用的材料】；24-2【粘贴目录，写编号和页码】 |
| 听完要记住的三件事（可让AI先提） | 页面堆砌，没有主线 | 24-1 第1项 |
| 听众最可能问的三个问题 | 现场答不上；问答准备缺位 | 24-1 第2项 |
| 研究结果原文的图表或表格、研究名称、材料编号和页码 | 数据页数字与原文对不上 | 24-3 输入槽位 |
| 是否有两项以上不同研究要放进幻灯片 | 被画进同一张图跨研究比较 | 24-3 第4项 |
| 讲者专业方向和题目（不写姓名）；讲者是否要加自己的病例 | 替讲者写观点；病例未去标识；加页未审 | 24-4 输入与沟通单第3项；「讲者的情况」 |
| 幻灯片是否带讲者备注、是否有配图及是否AI生成 | 备注里有未审内容；AI配图被当成真实资料 | 24-5 输入「讲者备注」、第6项 |
| 汇报：要汇报的事、听的人、时长、有哪些数据及来源 | 结论放最后；无来源 | 24-6 输入槽位 |
| 公司有无幻灯片模板、送审流程、AI标识规定 | 格式或流程不符 | 「喂给 AI 的材料」公司的规定 |

**红线/固定约束**：
- 「材料回答不了的，写「材料不足」，不要补。」——提示词 24-1
- 「不能出现的内容：说明书以外的用法、没有依据的比较、绝对化的词」——提示词 24-1 第4项
- 「每页写用哪份材料、第几页；找不到材料的页，标「材料不足」，不要编」——提示词 24-2 第2项
- 「讲疗效的页后面，要有讲重要安全性信息的页」——提示词 24-2 第4项
- 「纵轴从 0 开始，不截断」——提示词 24-3 第1项
- 「原文里的每个组都画出来，不删组，不合并」——提示词 24-3 第2项
- 「亚组和探索性分析，写明「探索性」」——提示词 24-3 第3项
- 「两项不同研究的结果，不放进同一张图里比较」——提示词 24-3 第4项
- 「只用给你的数字；图上要标的数字，和原文逐个对上。」——提示词 24-3
- 「公司提供审核过的资料页，讲者自己的临床经验和观点，由讲者自己写。公司不替讲者写观点，讲者加的页要再审。」——第三节导语（24-4 前）
- 「讲者想加自己的病例和经验：病例要去标识；加的页在讲课前交公司，按流程审核」——提示词 24-4 沟通单第3项
- 「讲者被问到说明书以外的问题：由讲者按自己的判断回答，公司的幻灯片里不准备这类内容」——提示词 24-4 沟通单第4项
- 「不替讲者写观点和结论，不写「专家认为」这类话。」——提示词 24-4
- 「请逐页检查，只列问题，不改写：」——提示词 24-5
- 「讲者备注里，有没有说明书以外的内容和没有依据的说法」——提示词 24-5 第5项
- 「图片：AI 生成的图片有没有按规定标识；有没有人物照片、医学影像这类会被当成真实资料的图」——提示词 24-5 第6项
- 「第一页写最重要的结论，和要对方决定的事」——提示词 24-6 第1项
- 「不利的数据和没把握的地方，单独一页」——提示词 24-6 第5项
- 「还没发布的幻灯片初稿，只放进公司批准的工具；含未公开数据的，只在公司批准的内部部署工具里用。」——「喂给 AI 的材料」红黄绿灯

**提示词清单**：
| 编号 | 标题 | 一句话用途 | 需要用户提供的输入 | 产出形态 |
|---|---|---|---|---|
| 24-1 | 幻灯片需求单：先写清楚，再动手 | 动手前定听众、时长、三件事、禁区 | 幻灯片类型、听众、时长、讲者、审核过的材料（编号版本） | 一页需求单（5项） |
| 24-2 | 故事线：每页一个结论，每页对应一份审核过的材料 | 排故事线，不写内容 | 24-1 需求单、审核材料目录（编号页码） | 故事线表（页码、页标题、材料编号页码、作用） |
| 24-3 | 数据页：按原文重画，写清脚注 | 为每个数据页写画图说明 | 研究名称、原文图表、材料编号页码 | 每页画图说明（类型、坐标、脚注、一句话标题） |
| 24-4 | 给专家的讲课幻灯片：资料包和讲者沟通单 | 给专家准备资料包和沟通单，不替讲者写观点 | 题目与听众、讲者专业方向（不写姓名）、24-2/24-3 结果或已审核幻灯片编号 | 资料包（每页标编号）+讲者沟通单 |
| 24-5 | 幻灯片送审前：逐页查，只列问题 | 送审前逐页六项检查 | 逐页文字、图表说明、讲者备注；说明书、参考文献原文、已审核核心信息 | 问题清单（页码、问题、依据），按严重程度排序 |
| 24-6 | 汇报幻灯片：页标题连起来，就是结论和理由 | 按金字塔原理排给管理层的汇报 | 汇报事项、听众、时长、材料（含来源） | 汇报幻灯片结构（首页结论与决策点、理由页、不利数据页） |

**可复用构件**：
- 24-1 的「需求单」五项（可作为任何幻灯片/汇报的前置追问清单）。
- 24-2 故事线表模板与排序「临床问题 → 证据 → 怎么用 → 安全性 → 要点回顾」。
- 24-3 的数据页检查点（纵轴、不删组、探索性标注、脚注字段：研究名称、人群、样本量、终点、统计方法、P 值或置信区间）。
- 24-4 的「资料包+讲者沟通单」结构。
- 24-5 六项逐页自查表；24-6 的「页标题连读」检查法。
