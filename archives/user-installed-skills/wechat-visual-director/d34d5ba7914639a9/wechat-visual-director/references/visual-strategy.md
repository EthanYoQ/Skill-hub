# WeChat Visual Strategy

## Image Roles

| Role | Use | Best Source |
|---|---|---|
| Cover | Promise, tension, central metaphor | Generated |
| Product proof | UI, repo, CLI, actual result | Screenshot |
| Explanation | Architecture, workflow, mechanism | Generated or diagram |
| Comparison | Before/after, choices, tradeoffs | Infographic |
| Scene | Workplace pain or decision moment | Generated |
| Evidence | Source quote, timeline, chart | Screenshot or chart |

## Route Patterns

Use these as starting points, not fixed presets.

- Documentary desk scene: real-feeling work surface, screen context, human traces, restrained color.
- Mechanism board: whiteboard/blackboard/system map with few labels, visual hierarchy.
- Editorial metaphor: one strong object or scene standing for the article tension.
- Product proof strip: real screenshot plus small annotated callouts.
- Consulting canvas: matrix, timeline, flywheel, or decision tree with high information density.
- Cinematic contrast: split scene showing old workflow vs new workflow.

## Anti-Patterns

- Same warm hand-drawn illustration for every section.
- Random abstract shapes with no explanatory job.
- Fake UI that looks unrelated to the actual product.
- Dense generated Chinese text.
- Over-clean corporate stock illustration.
- Cover template reused for body images.
- Images that only repeat the heading in visual form.

## Prompt Requirements

Each prompt should specify:

- Article context in one sentence.
- Image role and reader takeaway.
- Concrete subject matter.
- Composition and camera.
- Visual language.
- Color/mood, but not as the only differentiator.
- Aspect ratio and mobile readability.
- Text policy: no text, or exact short labels.
- Negative constraints.
